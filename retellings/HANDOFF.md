Что нужно знать, чтобы продолжить с этого места. Состояние на 22 августа 2026.

## Первое, что сделать

```bash
python3 tools/doctor.py
```

Скажет, что в этом окружении запустится: какие ключи заполнены (только имена, никогда
значения), есть ли ffmpeg / PIL / node, доступны ли API по сети, какие каталоги платных
кадров пусты. То же печатается на старте сессии хуком `.claude/hooks/session-start.sh`.

**Генерировать голос и кадры можно только там, где есть ключи и сеть** — то есть на
машине автора. Писать текст, код и профили голоса можно где угодно.

## Дальше, по шагам

```bash
python tools/build_retelling.py --spec retellings/<slug>/script.json --dry-run
python tools/build_retelling.py --spec retellings/<slug>/script.json --voice-only
#   -> voice/<slug>_build/voice.wav — ПОСЛУШАТЬ на ударения
python tools/build_retelling.py --spec retellings/<slug>/script.json --images-only
#   -> voice/<slug>_build/stills-contact-sheet.jpg — ПОСМОТРЕТЬ все кадры
```

Каждый этап кэшируется по имени файла: правка одного такта перегенерирует один такт.

## Что здесь стоило крови

**Паузы решают досматриваемость, и это измерено на самом канале** (скилл `yt-analytics`).
«Сила идеала» с максимальной паузой 0.8 с — 73% досмотра; «Ветер не выбирает» с 3.0 с —
15%; «Река не спорит с берегом» с 3.6 с — 5%. Обвал начинается ровно на паузе.

Отсюда: `pause_after` = 0.4 между рабочими тактами, 0.7 после `quiet`, 0.6 после
`return`. Реальный зазор выходит на ~0.45 с длиннее заданного — столько тишины Inworld
оставляет в хвосте такта. **Хронометраж нельзя добирать паузами**, рычаг длины — темп
чтения.

**Клипы музыкальной библиотеки затухают на своих краях**, и конвейер зацикливал их
сырыми: `ambient-pad` падает с −42 до −90 дБ за последние четыре секунды, то есть
подложка проваливалась в тишину каждые 63 секунды. Исправлено — края обрезаются,
зацикливается только звучащее тело, `dynaudnorm` выравнивает динамику. Уровень
подложки для этого трека `MUSIC_DB = -18` против −24 у шестидесятисекундных эпизодов.

Проверять готовый ролик так:

```bash
ffmpeg -i output/<slug>.mp4 -af "silencedetect=noise=-40dB:d=0.5" -f null /dev/null
```

## Уборка

Один пятиминутный пересказ оставляет ~800 МБ, из них 620 МБ — черновики ffmpeg.

```bash
python tools/cleanup.py          # показать
python tools/cleanup.py --yes    # удалить
```

Скрипт не трогает ничего отслеживаемого git, `raw-footage/`, оплаченные кадры и кэш
TTS, а рендер без живых исходников пропускает с предупреждением.
