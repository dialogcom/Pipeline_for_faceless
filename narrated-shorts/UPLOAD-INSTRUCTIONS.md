# Инструкции по загрузке видео на YouTube

## Серия «Тайна времени» (5 эпизодов)

**Скрипт**: `tools/upload_taina_vremeni.py`

**Даты публикации** (через день, 10:00 Алматы):
- Эп. 1: 14 октября 2026
- Эп. 2: 16 октября 2026
- Эп. 3: 18 октября 2026
- Эп. 4: 20 октября 2026
- Эп. 5: 22 октября 2026

**Команды**:
```bash
# Авторизация (первый раз)
python3 tools/upload_taina_vremeni.py --auth

# Загрузить все 5 эпизодов
python3 tools/upload_taina_vremeni.py --upload-all

# Загрузить один эпизод
python3 tools/upload_taina_vremeni.py --upload 1

# Посмотреть список
python3 tools/upload_taina_vremeni.py --list
```

## Серия «Последний вулкан» (перенесённые эпизоды)

**Скрипт**: `tools/upload_vulkan_rescheduled.py`

**Удалённые эпизоды** (низкие просмотры, 8-9 сентября):
- Эп. 3: "Правило было под рукой — трижды" → перенесён на 13 октября
- Эп. 5: "Что стоило это число?" → перенесён на 15 октября

**Команды**:

```bash
python3 tools/upload_vulkan_rescheduled.py --upload-all

# Загрузить один эпизод
python3 tools/upload_vulkan_rescheduled.py --upload 3
```

## Анализ низких просмотров (8-12 сентября)

### Причины:
1. **Переизбыток контента**: 14 видео за 5 дней (2-3 в день)
   - Алгоритм YouTube не успевает продвигать каждое видео
   - Видео конкурируют друг с другом за охваты

2. **Слабые hook (первые 3 секунды)**:
   - ✅ Успешное видео (1124 просм.): "Одно число стоило две жизни" — интрига, парадокс
   - ❌ Неудачные: абстрактные заголовки без конкретики

3. **Неоптимизированные описания**:
   - Мало ключевых слов в первых 2 строках
   - Хэштеги в конце, а не в теле описания

### Новая стратегия:
- **Частота**: 3-4 видео в неделю (не более 1 в день)
- **Время**: 04:00 UTC (10:00 Алматы) — оставляем
- **Описания**: оптимизированы с ключевыми словами в начале
- **Hook**: конкретика (числа, имена, парадокс) в заголовке
