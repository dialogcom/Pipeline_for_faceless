# claude-faceless-shorts-creator - обзор проекта

> Снимок состояния на **19 августа 2026**. Документ самодостаточный: его можно читать
> отдельно от репозитория, без доступа к коду. Внутри - что за проект, как он устроен,
> что уже сделано, по каким правилам он собирается и что делать дальше.

---

## 1. Что это

Фабрика вертикальных коротких видео (Shorts / Reels / TikTok), которой управляет Claude Code.
Видео собираются **программно**: сценарий, озвучка, картинки, анимация и звук производятся
скриптами и кодом, а не в видеоредакторе. Человек участвует на трёх контрольных точках -
утверждает сценарий, слушает озвучку на предмет ударений и смотрит финальный монтаж.

Формат по умолчанию: **1080x1920, 30 fps, 40-65 секунд**, без говорящей головы (faceless).

В репозитории живут **пять независимых производственных треков**. Нужный выбирается
автоматически по формулировке запроса.

| Запрос звучит как... | Трек (skill) | Откуда берутся пиксели | Где лежат проекты |
|---|---|---|---|
| «сделай шорт про X» (по умолчанию) | `/make-short` | 100% TSX-анимация (Remotion) | `shorts/short-N-<ниша>/` |
| «сделай AI-видео», «ролик про синего человека» | `/make-ai-short` | видеомодель через fal (закреплённый персонаж) | `ai-shorts/<серия>/` |
| «в стиле Vox», «документалка», «объяснялка» | `/make-vox` | слоёный бумажный коллаж (AI-картинки + вырезки) | `vox-shorts/vox-N-<тема>/` |
| серия озвученных роликов из набора сценариев | `/make-narrated-short` | Inworld TTS поверх AI-стилов (Ken Burns), голый ffmpeg | `narrated-shorts/<серия>/` |
| «нарежь мою запись созвона на серию» | `/repurpose-recording` | собственная запись пользователя | `media/projects/<slug>/` |

Первые три треки делят общий контракт `beats.json`, озвучку с пословной синхронизацией
субтитров и сборку на TSX. Четвёртый и пятый - чистый Python + ffmpeg, без Remotion.

### Жёсткие правила репозитория

- **Всё запускается из корня репозитория.** Инструменты находят движковые пути (медиа-библиотеку,
  каталоги) относительно себя, а пути проектов (`shorts/...`) - относительно текущей директории.
- **Реестр сцен генерируется.** После добавления или переименования сцены обязательно
  `cd remotion && npm run gen`. Скрипты рендера сами его не запускают.
- **`media/library/` - только для того, что переиспользуется между роликами** (у каждой папки
  свой каталог). Всё, что сделано ДЛЯ ОДНОГО ролика, идёт в `media/projects/<проект>/` и
  подключается как `staticFile('projects/<проект>/x')`. Перед генерацией нового - проверить каталоги.
- **Что коммитится:** AI-клипы, слои коллажа и стиллы в `media/projects/` - да (это платные,
  невоспроизводимые пиксели). Папки `*/voice/` и `*/output/` - нет (восстанавливаются бесплатно).
- **QA не опционально.** Кадры при телефонном масштабе рендерятся и ПРОСМАТРИВАЮТСЯ до полного рендера.
- **Стоимость называется заранее** (актуально для ai-shorts): сколько будет стоить генерация -
  говорится ДО того, как деньги потрачены.

## 4. Инструменты (`tools/`)

**Голос и текст**
- `gen_voice.py` - озвучка ElevenLabs с пословными таймингами
- `gen_voice_inworld.py` - озвучка Inworld (нативные русские голоса, тайминги встроены)
- `vo_from_recording.py` - вытащить озвучку из готовой записи
- `transcribe.py` / `transcribe_local.py` - расшифровка
- `segment_episodes.py` - разбиение длинной записи на эпизоды

**Картинки и слои**
- `gen_image.py`, `gen_image_cloudflare.py`, `gen_image_fal.py`, `gen_image_modelscope.py` - генерация по разным маршрутам
- `cutout.py` - вырезка объекта (rembg)
- `capture_web.py` - HTML → PNG через headless-браузер
- `matte_frame.py`, `rebuild_with_cf_images.py` - служебные

**Видео**
- `gen_clip.py` - AI-видеоклип
- `bakeoff_clip.py` - сравнение моделей на одном промпте
- `build_narrated_short.py` - сборка ролика трека narrated-shorts целиком
- `build_retelling.py` - сборка длинного пересказа, 9:16 или 16:9
- `build_repurposed_episode.py` - сборка эпизода из нарезанной записи
- `add_intro_bumper.py` - вставка заставки

**Текст и голос автора**
- `analyze_voice.py`, `voice_corpus.py`, `voice_metrics.py` - построение профиля голоса из текстов
- `audit_voice.py` - детерминированная оценка черновика по профилю, 100 баллов, порог 80

**Хозяйство**
- `doctor.py` - что запустится в этом окружении: ключи, инструменты, сеть, платные кадры
- `cleanup.py` - уборка диска; удаляет только игнорируемое git и воспроизводимое
- `eleven_keys.py` - пул ключей ElevenLabs с авто-переключением по квоте

**Звук**
- `gen_sfx.py` - генерация звуковых эффектов (сейчас заблокирована правами ключа)
- `gen_music.py`, `gen_chords.py` - музыкальная подложка
- `mix_sfx.py` - микс SFX по плану `sfx-plan.json` с приглушением под голос
- `mix_music.py` - подмешивание музыки

## 5. Общий конвейер

Порядок неслучаен: каждый шаг фиксирует данные для следующего.

1. **Сценарий.** Для серий - историческая параллель + реплики предлагаются ДО генерации
   озвучки и ждут подтверждения человека.
2. **Озвучка - ПЕРВОЙ, до любого кода сцен.** Реальная длительность может сильно отличаться
   от прикидки на глаз. Один раз ролик строили по угаданному таймингу, озвучка оказалась
   почти вдвое длиннее, и всю вёрстку пришлось делать заново.
3. **Проверка ударений человеком.** Файлы отправляются на прослушивание. Стандартная
   акцентная метка (combining acute, U+0301) помогает не всегда - иногда движок просто не
   может произнести слово правильно, и тогда переписывается сам текст, а не ударение.
4. **Картинки** генерируются и **отправляются на утверждение до вставки в сцены** - это
   отдельная просьба пользователя, был случай с плохим «мультяшным» лицом.
5. **Сборка сцен** (TSX или ffmpeg). Границы сцен = точные старты реплик озвучки.
6. **QA кадрами** при телефонном масштабе, шаг примерно 2 секунды по ключевым моментам.
   Кадры именно просматриваются, а не просто рендерятся.
7. **Полный рендер** (3-6 минут) и подмешивание голоса.
8. **SFX** по плану, привязанному к событиям на экране, с обязательным прослушиванием человеком.

## 6. Состояние по трекам

### 6.1 vox-shorts - документальный сериал (активная работа)

Серия из 7 эпизодов по 55-65 секунд. Каждый соединяет духовную концепцию Шри Чинмоя с
исторической параллелью. Технически - эксперимент поверх vox-движка: сцены собираются как
TSX-код, реального видеомонтажа нет.

| № | тема | длительность | состояние |
|---|---|---|---|
| 11 | Falcon 1 / трудность духовного пути | 54с | доставлен |
| 12 | Листер и микробы / парадокс осознанности | 61с | доставлен |
| 13 | Сухой закон / тигр желаний | 62с | доставлен |
| 14 | Золотая лихорадка / ловушка сравнения | 63с | **переделан в стиле vox-17 (19.08)** |
| 15 | Кража Моны Лизы / вор в доме покоя | 63с | **переделан в стиле vox-17 (19.08)** |
| 16 | Ошибка 1202, Аполлон-11 / сомнение на пороге | 56.5с | **переделан в стиле vox-17 (19.08)** |
| 17 | Мёртвая петля Кони-Айленда 1895 / взлёты и падения | 64.3с | доставлен |

**Стиль vox-17 принят как новый стандарт серии** (утверждено 19.08 на эпизоде 16):
«качественно лучше, лучше удерживает внимание, нет 2-3-секундных зависаний, когда ничего
не происходит». Порядок переделки старых эпизодов: 16 → 15 → 14 → 13 → 12 → 11.
Сделаны 16, 15, 14.

Из чего состоит этот стиль:

1. **Одна сквозная линия, меняющая состояние в каждой сцене.** Не четыре отдельные
   иллюстрации, а одна метафора, которая физически превращается. Зритель следит за одним объектом.
2. **Каждая линия рисует себя** по параметрической полилинии, и по тому же параметру едет
   объект, который её «везёт». Момент дорисовки привязан к КОНКРЕТНОМУ слову озвучки,
   а не к началу сцены.
3. **Информация вместо украшений.** Шкалы, отметки, подписи - всё читается. Плюс один чип
   с фактом, которого НЕТ в озвучке, чтобы нижняя треть не пустовала и не дублировала голос.
4. **Ни одной статичной секунды.** Если в сцене фото - поверх него идёт живой элемент.
5. **Подписи гаснут вместе со своим смыслом**, иначе подпись переживает объект.
6. **Единый тёмный тон** во всех сценах.
7. **SFX перекраиваются под новые события**, а не остаются от прошлой версии.

Сквозные объекты уже сделанных переделок (чтобы не повторяться):

- **vox-16** - траектория спуска: падение → развилка → подъём → зигзаг → спираль.
- **vox-15** - РАМА: пустая рама в Лувре → таймлайн беспечности → рама вокруг покоя,
  которую растаскивают три вора → подъём к финишу с трескающимся трофеем.
- **vox-14** - ЛИНИЯ СОБСТВЕННОЙ ЖИЗНИ: ровный участок «дом, семья, своё дело», который
  перерезают → дорога на запад с отметками БОЛЕЗНИ / НИЩЕТА / СМЕРТЬ рядом с бледной
  непройденной линией «своё призвание», которая обрывается → алтарь под медитирующим,
  который трое соперников выдёргивают из горизонтали и превращают в биржевой график →
  та же линия, сложенная в ДВЕРЬ, через которую утекает золото.

**Правило номер один при переделке: озвучку не трогаем.** Голос, пословные тайминги и
границы сцен остаются теми же, меняется только нарисованное. Поэтому переделка бесплатна и быстра.

Эпизод 17 заканчивается тизером восьмой серии - про **эго**, «тот, кто на каждом вираже
шепчет вам, что это вы сами взлетели».

Кроме сериала в этом треке лежат ролики про персонажа Петю (vox-8, vox-9) и более ранние
эксперименты (vox-1..vox-7, код сцен в Remotion).

### 6.2 narrated-shorts - диктор поверх AI-стиллов

Самый простой трек технически: голый Python + ffmpeg, без Remotion и Node.js. Три серии:

| серия | эпизодов в scripts.json |
|---|---|
| `guru-i-uchenik` | 17 |
| `trudnosti-puti` | 12 (есть готовые описания для YouTube) |
| `put-i-istoriya` | 1 |

`scripts.json` - источник истины для серии. Это единственный трек, где сознательно допускается
CTA в конце - решение обсуждалось отдельно и записано в его `DESIGN.md`.
У трека есть собственный `HANDOFF.md` - инструкция «с нуля до отрендеренного видео» для
нового компьютера или человека.

### 6.3 shorts - TSX-анимация

В Remotion лежит код 27 шортов (`short-1` .. `short-27`). В рабочей папке `shorts/` сейчас
только два последних проекта - `short-25-aphorism-sunrise` и `short-26-aphorism-mountain`,
остальные подчищены с диска после доставки.

### 6.4 ai-shorts - генеративное видео

Серия `blue-man`: закреплённый повторяющийся персонаж, анимированный видеомоделью через fal,
с бесшовной петлёй (первый кадр совпадает с последним). Есть `IDEAS.md` с банком идей, чтобы
не переобсуждать выбор модели каждый раз.

**Железное правило трека:** закреплённого персонажа НИКОГДА не генерируют заново из текста -
только от сохранённого референса. И стоимость генерации называется до траты.

### 6.5 repurpose-recording - нарезка чужих записей

Превращает одну длинную запись (созвон, вебинар, лекцию) в серию вертикальных роликов, где
повествование обрывается на полуслове и мостиком идёт озвученный вопрос «возвращайтесь за
продолжением». Смысл структуры - ограничить, сколько исходника зритель получает за один пост.
Проект `rossienko-talk` собран этим треком.

### 6.6 retellings - длинные пересказы (главная активная работа)

Шестой трек и единственный, который собирает **горизонтальное** видео. Берёт уже готовый
короткий ролик и пересказывает его на 4-6 минут по семитактовой схеме
(`retellings/STORY-STRUCTURE.md`, выведена из семи рассказов Чехова и семи О. Генри):
`hook - scene - break - three - quiet - turn - return`. Диктор Inworld, ~22 AI-кадра,
Ken Burns и кроссфейды, субтитры пословно, чистый ffmpeg, без Remotion.

**Формат объявляется в спеке:** `"format": "16:9"` даёт 1920x1080 под YouTube,
`"9:16"` (по умолчанию) - телефонный кадр. Форма разрешается один раз в `spec_format()`,
после чего её получают все стадии, поэтому субтитр и кадр не могут разойтись. 16:9 - не
повёрнутый 9:16: другая геометрия субтитров, вдвое более длинный кроссфейд, логотип
**меньше** по доле кадра (150px на 1920 против 170 на 1080), и промпты приходится писать
заново, потому что широкому кадру надо объяснить, чем заняты бока.

**Сюжет для пересказа ищут, а не растягивают.** Исходные шорты - это метафоры и учения,
в них нет ни проверяемого факта, ни того, чему переворачиваться. Пять минут добываются
исследованием: «тигр желаний» стал лабораторией Скиннера и парадоксом Хамфриса, «вулкан
сомнения» - контрольным временем на Эвересте в 1996-м. Каждое проверяемое утверждение
уходит в `<slug>/script.md` с источником.

**Состояние:** `petlya-i-spiral` собран (4:56) и опубликован на YouTube 22.08.2026;
`tigr-na-diete` и `posledniy-vulkan` написаны и ждут только кадров - и суточного
потолка на них больше нет: маршрут Model Studio (`tools/gen_image_alibaba.py`) отдаёт
1080x1920 подряд, в пределах недельной квоты подписки.

Подробности - `retellings/HANDOFF.md` и `retellings/DESIGN.md`.

## 7. Договорённости с пользователем

Накоплено по ходу работы; нарушение любого пункта - повод переделывать.

**Текст и стиль**
- В любом тексте использовать короткое тире `-`, не длинное. Длинное читается как «написано ИИ».
- Не оставлять висящий CTA и не дублировать голосом то, что уже написано на экране.
  Сценарий должен доводить мысль до конца, даже если исходное задание этого не делает.
- Слова, которые синтезатор произносит с неправильным ударением, заменять на благозвучные
  альтернативы, а не бороться с разметкой ударений.

**Картинка**
- Логотип-птица присутствует на каждом ролике; в vox-роликах он должен быть крупнее и
  никогда не наезжать на заголовок.
- Персонаж Петя во всех новых роликах получает подстроенное под настроение покачивание
  (`characterSway()`); семь старых роликов задним числом не переделывались.
- Не оставлять сцену статичной картинкой на 10+ секунд. Для статичных пауз под голос
  использовать медленный проезд по кадру.
- Если два соседних куска хроники не стыкуются по цвету - не подгонять цвет, а размыть и
  подписать. Иногда так выглядит лучше.
- Схематичная карта или диаграмма: контур должен быть ОДНОЙ чёткой читаемой линией, а не
  абстрактной кляксой; линии-потоки должны видимо упираться в контур, а не висеть в воздухе.
- Пользователь явно предпочитает информативные элементы декоративным.

**Звук**
- Громкость SFX ставить тише инстинкта примерно на 3 дБ. Ключевые акценты около -9/-10 дБ,
  необязательные -14/-17 дБ. Однажды звук забил голос, и всё пришлось пересводить.

**Процесс**
- Полный QA только для новых визуальных приёмов; для переиспользуемых шаблонов достаточно
  лёгкой проверки двумя кадрами.
- Никогда не удалять картинку или рендер до того, как замена реально сгенерировалась -
  квоты могут отказать посреди правки.
- Реальных публичных людей: живого узнаваемого человека пытаться сделать похожим, и если
  модель отказывается - честно сказать. Давно умерших исторических деятелей делать дженериком
  без требования портретного сходства.

## 8. Технические грабли (уже пройденные)

- **`AbsoluteFill` внутри камеры коллажа не рисует ничего.** Обёртка камеры - div без
  собственных размеров, поэтому элемент со стопроцентными размерами схлопывается в 0x0.
  Все полноэкранные градиенты и тонировки, написанные так, молча не появляются. Решение -
  локальный `BoardFill`: обычный div с явными координатами и заведомо большими размерами.
- **Субтитры рисуются сверху** (отступ 250 px) и в 3-4 строки доходят примерно до 440 px.
  Всё, что в сцене выше этой отметки, попадёт под них.
- **Крупный экранный текст рисуется ВНЕ камеры**, а сцена - внутри, с зумом. Позицию объекта
  на экране надо пересчитывать через зум камеры, а не прикидывать на глаз.
- **Первые полторы секунды новой сцены легко оказываются пустой доской**, пока линия только
  начинает чертиться. Лечится бледным «планом» будущей линии плюс куском линии, приезжающим
  из предыдущей сцены.
- **Генератор реестра сцен ищет литеральные числа** ширины и высоты. Переменная вместо числа
  молча даёт горизонтальный формат по умолчанию.
- **Синтезатор Inworld склеивает дефис с предыдущим словом**, и это видно в субтитрах.
  Чинить в копии файла таймингов для субтитров; исходники в папке озвучки не трогать -
  они должны соответствовать аудио.
- **`rembg` не ставится через pip** на этой машине из-за конфликта пакетов - только через conda,
  и запускать с отключённым пользовательским site-packages.
- **Штатный скрипт картинок Cloudflare падает**, потому что принудительно шлёт ширину и высоту.
  Рабочий вариант - квадрат без этих параметров, шаблон скрипта хранится в `vox-shorts/HANDOFF.md`.
- **У Model Studio два несовместимых ключа.** Ключ подписки (`sk-sp-`) ходит только на свой
  хост `token-plan.<регион>.maas.aliyuncs.com`, обычный ключ (`sk-`) - только на `dashscope`,
  а ключ qwen-code (`o1__`) не подходит никуда. Перепутанная пара отвечает `InvalidApiKey`,
  что читается как «плохой ключ», хотя плохой там хост. На подписке нет асинхронного API,
  поэтому кадр берётся синхронным эндпойнтом. Всё это уже разведено внутри
  `tools/gen_image_alibaba.py`; бесплатная проверка ключа - `--models`.
- **Бесплатные звуки с Pixabay** не скачиваются кнопкой из браузерного инструмента. Рабочий
  способ - достать прямую ссылку на файл из плеера страницы и скачать её напрямую, потом
  нормализовать громкость и вручную добавить запись в каталог.

## 9. Состояние диска и восстановление

Диск забивается быстро: один пятиминутный пересказ оставляет около 800 МБ, из которых
620 МБ - черновики ffmpeg, нужные ровно до конца сборки. Уборку проводят регулярно, и
делает её инструмент, а не память человека:

```bash
python tools/cleanup.py          # только показать, ничего не удаляя
python tools/cleanup.py --yes    # удалить
```

Он удаляет только то, что игнорирует git, плюс сверх того защищает `raw-footage/`
(исходники автора) и кэш TTS (оплачен). Рендер, у которого не осталось живых исходников,
он не трогает, а предупреждает - так уцелели рендеры vox-17 после того, как их слои
были удалены.

Пользователь также периодически чистит рабочие копии вручную, оставляя всё в гите.
В новой сессии тогда сначала нужно восстановить, иначе рендер падает:

```bash
git restore media/projects vox-shorts
cd remotion && npm install --no-audit --no-fund
```

- `remotion/node_modules` в гит не входит - без установки зависимостей проект не собирается.
- Логотип-птица и библиотека SFX тоже сносятся чисткой, а без них рендер падает с ошибкой 404.
- Финальные файлы лежат в `<проект>/output/` и **не хранятся в гите** - они могут быть удалены.
  Если их нет на диске, не надо молча всё перегенерировать: сначала спросить, сохранил ли
  пользователь уже присланное. Визуал, рендер и микс восстанавливаются бесплатно из кода и
  озвучки; деньги нужны, только если придётся заново звать генерацию картинок или голоса.

**Важная потеря:** у эпизодов vox-11, vox-12 и vox-13 слои и озвучка стёрты ДО коммита и
восстановлению не подлежат. Тексты всех реплик целы в файлах таймингов, расшифровывать не
надо, но голос и картинки придётся генерировать заново - платно, и тайминги будут другими,
то есть сцены придётся верстать с нуля. У vox-14..17 слои, озвучка и тайминги в гите есть.
